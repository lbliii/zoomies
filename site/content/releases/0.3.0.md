## Highlights

- **QPACK dynamic table** — Full RFC 9204 encoder/decoder with bounded eviction and adversarial protection
- **QUIC client mode** — Client-side QUIC and HTTP/3, completing both sides of the wire
- **0-RTT early data** — PSK resumption with early data send/receive and anti-replay
- **Constant-time TLS verify** — Security hardening for Finished message comparison

## Added

### QPACK dynamic table (`zoomies.h3`)

- `DynamicTable` with size-bounded eviction for header field indexing
- Encoder and decoder instruction streams per RFC 9204
- `H3Connection` settings negotiation for `QPACK_MAX_TABLE_CAPACITY` and `QPACK_BLOCKED_STREAMS`
- Adversarial input protection (oversized inserts, blocked stream limits)
- Property-based tests (Hypothesis) for encode/decode roundtrip invariants

### QUIC client mode

- Client-initiated TLS 1.3 handshake with ClientHello generation
- Full client/server loopback integration tests
- HTTP/3 client request/response cycle over QUIC
- `client_server.py` example demonstrating end-to-end usage
- `QuicConfiguration` gains `is_client` flag for role selection

### 0-RTT early data

- Pre-shared key (PSK) storage and ticket-based resumption
- 0-RTT packet building and early data transmission
- Server-side early data acceptance and rejection
- Anti-replay protection for 0-RTT packets
- New events: `EarlyDataAccepted`, `EarlyDataRejected`
- Comprehensive test coverage: crypto, connection, client, and end-to-end

### Documentation site

- GitHub Pages deployment workflow with Bengal static site generator
- Concept guides: sans-I/O, free-threading, HTTP/3, connection lifecycle
- Reference docs: connection API, events, configuration
- Tutorials: echo server, quickstart, installation

## Security

- TLS Finished message verification now uses `hmac.compare_digest` for constant-time comparison, preventing timing side-channel attacks

## Status

- Beta: full TLS 1.3, 1-RTT, 0-RTT, loss recovery, congestion control, client + server mode
- Sans-I/O design, typed, free-threading ready
