## Highlights

- **Public API exports fixed** — 0.3.0 features (0-RTT events, QPACK encoder/decoder) are now importable from the top-level package
- **Version corrected** — `__version__` now matches `pyproject.toml`

## Fixed

### Missing exports

- `ZeroRttAccepted` and `ZeroRttRejected` events now exported from `zoomies` package
- `QpackEncoder` and `QpackDecoder` now exported from `zoomies.h3`
- `__version__` bumped from `0.1.0` to `0.3.1` — was never updated alongside `pyproject.toml` in 0.3.0

### Documentation

- Corrected event names in 0.3.0 release notes: `ZeroRttAccepted`/`ZeroRttRejected` (was incorrectly listed as `EarlyDataAccepted`/`EarlyDataRejected`)
- Updated package docstring to document client mode, 0-RTT, and QPACK dynamic table APIs

## Status

- Beta: full TLS 1.3, 1-RTT, 0-RTT, loss recovery, congestion control, client + server mode
- Sans-I/O design, typed, free-threading ready
